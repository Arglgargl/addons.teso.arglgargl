# AwesomeLeadFilter

Adds additional filter capabilities for antiquity lead envelopes to AwesomeGuildStore by sirinsidiator.

Two new filter options named 'Unknown Codex' have been added to the Consumable / Miscellaneous sub-category:
- Never dug out: only shows lead envelopes for leads that have never been dug out
- Codex Entries: only shows lead envelopes for leads where not all codex entries are known 

If any of the filter options is active, only lead envelopes are shown.
